NOTF-01 bug: PairingActionReceiver's ACTION_APPROVE handler (lines 32-43 of PairingActionReceiver.kt) just cancels the notification and launches MainActivity with a navigation intent. It does NOT actually approve the pairing. The user expects tapping "Approve" on the notification to approve the pairing immediately, but instead it just opens the app to the Pairing Requests screen.

Per CONTEXT.md: "Test the handler/approval logic that the notification action triggers, not the notification dispatch itself."

The test should verify that when PairingActionReceiver receives an APPROVE action intent, it triggers actual pairing approval (sends PAIR_APPROVED SMS and updates device status) rather than just opening the app.

Since PairingActionReceiver currently uses `context.startActivity()` (not `context.startService()` for approve), the test verifies that the approve action should call MasterService (like reject does) rather than launching an activity.

Test approach using Robolectric:
```kotlin
@RunWith(RobolectricTestRunner::class)
@Config(sdk = [34])
class PairingActionReceiverTest {

    @Test
    fun `UAT NOTF-01 - approve action sends pairing approval to MasterService`() {
        val context = ApplicationProvider.getApplicationContext<Context>()
        val receiver = PairingActionReceiver()

        val intent = Intent().apply {
            action = PairingNotificationManager.ACTION_APPROVE
            putExtra(PairingNotificationManager.EXTRA_PHONE_NUMBER, "+5551234567")
        }

        receiver.onReceive(context, intent)

        // NOTF-01: Approve action should send to MasterService for processing
        // (like reject does), not just launch MainActivity
        // Currently: starts MainActivity with navigation intent
        // After fix: starts MasterService with PAIRING_APPROVE_REQUESTED action

        val shadowApp = Shadows.shadowOf(context as Application)
        val startedService = shadowApp.nextStartedService

        // Verify a service was started (not an activity)
        assertNotNull("Approve action should start MasterService, not just open activity", startedService)
        assertEquals(MasterService.PAIRING_APPROVE_REQUESTED, startedService.action)
        assertEquals("+5551234567", startedService.getStringExtra(MasterService.EXTRA_PHONE_NUMBER))
    }
}
```

This test FAILS because the current code starts an Activity (not a Service) for the approve action. `shadowApp.nextStartedService` returns null.
