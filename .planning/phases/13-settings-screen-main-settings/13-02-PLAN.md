# 13-02: Main Settings Preferences

## Objective

Implement the three main user-facing settings: notification persistence toggle, default forwarding duration selection, and theme selection. These go in the "Preferences" section created by Plan 13-01.

Purpose: Users can customize core app behavior (MAIN-02, MAIN-03, MAIN-04).
Output: Functional settings items with persistence via SettingsRepository.

## Context

@.planning/phases/13-settings-screen-main-settings/13-RESEARCH.md
@.planning/phases/13-settings-screen-main-settings/13-CONTEXT.md
@.planning/phases/13-settings-screen-main-settings/13-01-SUMMARY.md (after Plan 01 completes)

**From CONTEXT.md decisions:**
- Settings changes apply immediately (no save button)
- Notification persistence controls foreground service notification recreate behavior
- Theme options: Light, Dark, System (default System)
- Duration options: 15min, 30min, 1hr, 2hr (values: 15, 30, 60, 120)

**From RESEARCH.md:**
- Use Material3 ListItem for settings rows
- Switch for boolean settings
- DropdownMenu or SegmentedButtonRow for selection
- SettingsRepository validation accepts 1-60 for duration (15, 30, 60 all valid; 120 exceeds validation - see task notes)

**SettingsRepository API (from Phase 12):**
- `notificationPersistence: Flow<Boolean>` / `setNotificationPersistence(Boolean)`
- `defaultForwardingDurationMinutes: Flow<Int>` / `setDefaultForwardingDuration(Int)` (1-60 valid range)
- `theme: Flow<AppTheme>` / `setTheme(AppTheme)`

**1. Create reusable SettingsListItem composables:**

```kotlin
@Composable
private fun SettingsSwitchItem(
    title: String,
    subtitle: String,
    checked: Boolean,
    onCheckedChange: (Boolean) -> Unit,
) {
    ListItem(
        headlineContent = { Text(title) },
        supportingContent = { Text(subtitle) },
        trailingContent = {
            Switch(checked = checked, onCheckedChange = onCheckedChange)
        },
    )
}

@Composable
private fun SettingsSelectionItem(
    title: String,
    selectedValue: String,
    onClick: () -> Unit,
) {
    ListItem(
        headlineContent = { Text(title) },
        supportingContent = { Text(selectedValue) },
        trailingContent = {
            Icon(
                Icons.Default.KeyboardArrowDown,
                contentDescription = "Select",
                tint = MaterialTheme.colorScheme.onSurfaceVariant,
            )
        },
        modifier = Modifier.clickable(onClick = onClick),
    )
}
```

**Default Forwarding Duration (Dropdown):**

Create state for dropdown expanded:
```kotlin
var durationExpanded by remember { mutableStateOf(false) }
```

Duration options list (note: 120 exceeds SettingsRepository validation of 1-60, so use 60 as max):
```kotlin
val durationOptions = listOf(15, 30, 60)
```

Helper function for display:
```kotlin
fun formatDuration(minutes: Int): String = when (minutes) {
    15 -> "15 minutes"
    30 -> "30 minutes"
    60 -> "1 hour"
    else -> "$minutes minutes"
}
```

UI:
```kotlin
Box {
    SettingsSelectionItem(
        title = "Default forwarding duration",
        selectedValue = formatDuration(defaultDuration),
        onClick = { durationExpanded = true },
    )
    DropdownMenu(
        expanded = durationExpanded,
        onDismissRequest = { durationExpanded = false },
    ) {
        durationOptions.forEach { minutes ->
            DropdownMenuItem(
                text = { Text(formatDuration(minutes)) },
                onClick = {
                    viewModel.setDefaultForwardingDuration(minutes)
                    durationExpanded = false
                },
            )
        }
    }
}
```

**Theme Selection (Segmented Button Row or Dropdown):**

Using SegmentedButtonRow (follows PairedDevicesScreen.kt pattern):
```kotlin
val themeOptions = AppTheme.entries
var themeExpanded by remember { mutableStateOf(false) }

// Use ListItem with custom trailing content showing current theme, clicking opens dialog
// OR use SingleChoiceSegmentedButtonRow inline

// Option A: Segmented buttons (compact, visual)
Column(modifier = Modifier.padding(horizontal = 16.dp)) {
    Text(
        text = "Theme",
        style = MaterialTheme.typography.bodyLarge,
    )
    Spacer(modifier = Modifier.height(8.dp))
    SingleChoiceSegmentedButtonRow(modifier = Modifier.fillMaxWidth()) {
        themeOptions.forEachIndexed { index, appTheme ->
            SegmentedButton(
                selected = theme == appTheme,
                onClick = { viewModel.setTheme(appTheme) },
                shape = SegmentedButtonDefaults.itemShape(
                    index = index,
                    count = themeOptions.size,
                ),
            ) {
                Text(
                    when (appTheme) {
                        AppTheme.LIGHT -> "Light"
                        AppTheme.DARK -> "Dark"
                        AppTheme.SYSTEM -> "System"
                    }
                )
            }
        }
    }
}
```
