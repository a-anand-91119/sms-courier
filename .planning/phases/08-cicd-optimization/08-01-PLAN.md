<objective>
Create upload-only Fastlane lane that uses pre-built artifacts from CI, eliminating redundant gradle builds in deploy jobs.

Purpose: The current `deploy:internal` job has `needs: [build]` to get artifacts, but then calls `internal_with_metadata` which runs `gradle(task: "clean assembleRelease bundleRelease")` again. This wastes 3-5 minutes rebuilding already-built artifacts.

Output: New `upload_internal` lane that skips gradle, uses existing AAB artifact, and uploads to Play Store.
</objective>

**Problem Analysis:**
1. Build job creates `app-release.aab` artifact (line 114-117 in .gitlab-ci.yml)
2. Deploy:internal job depends on build artifacts (line 143-145)
3. BUT `internal_with_metadata` lane runs gradle AGAIN (line 154 in Fastfile)
4. This is wasteful - the AAB is already built

**Solution:**
- Create `upload_internal` lane that takes AAB path as parameter
- Skip gradle entirely
- Use the artifact from build job
- Update .gitlab-ci.yml to call new lane
</context>

<tasks>

<task type="auto">
  <name>Task 1: Create upload_internal lane in Fastfile</name>
  <files>fastlane/Fastfile</files>
  <action>
Add new lane `upload_internal` between `internal_with_metadata` and the promotion lanes section:

```ruby
desc "Upload pre-built AAB to internal track (no gradle build)"
lane :upload_internal do |options|
  version_code = options[:version_code] || ENV["VERSION_CODE"] || "1"
  aab_path = options[:aab_path] || "app/build/outputs/bundle/release/app-release.aab"

  # Verify AAB exists
  UI.user_error!("AAB not found at #{aab_path}") unless File.exist?(aab_path)

  # Generate changelog
  generate_changelog(version_code: version_code)

  # Upload without building
  upload_to_play_store(
    track: "internal",
    release_status: "draft",
    aab: aab_path,
    skip_upload_apk: true,
    skip_upload_metadata: false,
    skip_upload_changelogs: false,
    skip_upload_images: true,
    skip_upload_screenshots: true
  )
end
```

Key points:
- Takes `aab_path` parameter with sensible default
- Validates AAB exists before attempting upload
- Calls existing `generate_changelog` for changelog
- Does NOT call gradle
