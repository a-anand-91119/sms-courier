**In PairedDevicesViewModel.deleteDevice():** Only send UNPAIR SMS if the device was actually approved (pairing was established).

Update the method:
```kotlin
fun deleteDevice(device: PairedDevice) {
    viewModelScope.launch {
        sessionRepository.endSessionForDevice(device.phoneNumber, "USER")

        // Only send UNPAIR if pairing was actually established
        if (device.status == PairingStatus.APPROVED) {
            val roleToDeleteOnRemote = when (device.role) {
                DeviceRole.SOURCE -> DeviceRole.TARGET
                DeviceRole.TARGET -> DeviceRole.SOURCE
            }
            smsSender.sendUnpair(device.phoneNumber, roleToDeleteOnRemote)
        }
        // Skip UNPAIR for: REJECTED, PENDING_SENT, PENDING_RECEIVED
        // These devices either rejected us, we rejected them, or pairing never completed

        deviceRepository.deleteByPhoneNumberAndRole(device.phoneNumber, device.role)
    }
}
```

This is a simple conditional check. No database or DAO changes needed.

Rationale:
- REJECTED: Other device already knows we rejected them (received PAIR_REJECTED)
- PENDING_SENT: Our request wasn't responded to, they don't have us in their list
- PENDING_RECEIVED: We haven't approved yet, they're waiting for response
- APPROVED: Only status where both devices have each other paired
