<objective>
Fix UNPAIR to archive devices instead of hard delete

Purpose: UAT revealed that unpaired devices are permanently deleted instead of being soft-deleted (archived). The soft delete columns (is_archived, archived_at, archival_initiated_by) exist in the schema but no archive methods were implemented. This breaks the Device History feature which expects archived devices to appear in the "Removed Devices" section.

Output: UNPAIR operations (both SMS command and UI-initiated) will set is_archived=true instead of deleting the row, preserving device history for the Removed Devices section.
</objective>
