Use SimpleDateFormat with patterns:

**Then create ExportFormatter.kt:**

Create object `ExportFormatter` with:

1. **formatToString(data: ExportData, config: ExportConfig): String**
   - Dispatches to format-specific method based on config.format
   - Returns complete export content as String

2. **formatToCsv(data: ExportData, includeMetadata: Boolean): String**
   - RFC 4180 compliant CSV generation
   - Header row: "Session ID,Started At,Sender,Message,Timestamp"
   - If includeMetadata: prepend comment lines with device info, export date
   - Use `escapeCsvValue()` helper for proper escaping:
     - Wrap in quotes if contains comma, quote, or newline
     - Escape quotes by doubling them
   - Use DateTimeFormatters.formatExportDateTime for timestamps

3. **formatToJson(data: ExportData, includeMetadata: Boolean): String**
   - Nested structure per CONTEXT.md:
     ```json
     {
       "metadata": { ... },  // only if includeMetadata
       "sessions": [{
         "sessionId": 1,
         "startedAt": "2026-02-06T14:30:00+00:00",
         "durationMinutes": 60,
         "messageCount": 5,
         "isActive": false,
         "messages": [{ ... }]
       }]
     }
     ```
   - Use `escapeJsonString()` helper for proper escaping:
     - Escape: \\ (backslash first!), \", \n, \r, \t, \b, \f
   - Use DateTimeFormatters.formatIso8601 for timestamps
   - Build manually with buildString (no external library)

4. **formatToTxt(data: ExportData, includeMetadata: Boolean): String**
   - Chat log style per CONTEXT.md: `[2026-02-06 10:30] +1234567890: Message content`
   - If includeMetadata: header block with device info, separator line
   - Group messages by session with session header line
   - Use DateTimeFormatters.formatExportDateTime for timestamps

5. **Private helpers:**
   - `escapeCsvValue(value: String): String`
   - `escapeJsonString(value: String): String`
