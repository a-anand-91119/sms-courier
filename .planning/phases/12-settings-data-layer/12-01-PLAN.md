Create SettingsRepository following the pattern from RESEARCH.md:

**DataStore singleton:**
- Use top-level `preferencesDataStore` property delegate with name `"settings"`
- Extension on Context: `private val Context.settingsDataStore`

**Class structure:**
- Constructor takes `Context`
- Private `dataStore` property from `context.settingsDataStore`

**Read Flows (one for each setting):**
- `val notificationPersistence: Flow<Boolean>` - maps to default if unset
- `val defaultForwardingDurationMinutes: Flow<Int>` - maps to default if unset
- `val theme: Flow<AppTheme>` - stores as String name, converts via `AppTheme.valueOf()`
- `val lockoutDurationMinutes: Flow<Int>`
- `val maxFailedAttempts: Flow<Int>`
- `val challengeExpiryMinutes: Flow<Int>`
- `val maxPairingResendAttempts: Flow<Int>`
- `val pairingResendCooldownMinutes: Flow<Int>`
- `val authRequestTimeoutMinutes: Flow<Int>`

**Write methods (suspend functions with validation per CONTEXT.md):**
- `suspend fun setNotificationPersistence(enabled: Boolean)` - no validation needed
- `suspend fun setDefaultForwardingDuration(minutes: Int)` - require 1..60, throw `IllegalArgumentException` if invalid
- `suspend fun setTheme(theme: AppTheme)` - no validation needed
- `suspend fun setLockoutDuration(minutes: Int)` - require 1..60
- `suspend fun setMaxFailedAttempts(attempts: Int)` - require 1..10
- `suspend fun setChallengeExpiry(minutes: Int)` - require 1..10
- `suspend fun setMaxPairingResendAttempts(attempts: Int)` - require 1..10
- `suspend fun setPairingResendCooldown(minutes: Int)` - require 1..10
- `suspend fun setAuthRequestTimeout(minutes: Int)` - require 1..30

Use pattern: `require(value in range) { "descriptive error" }` before `dataStore.edit {}`
