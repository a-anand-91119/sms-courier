<task type="auto">
  <name>Task 2: Add live countdown timer in dropdown</name>
  <files>app/src/main/java/dev/notyouraverage/smscourier/composables/screens/PairedDevicesScreen.kt</files>
  <action>
Make the cooldown timer tick down live while the dropdown is open:

1. In DeviceList composable, when rendering the DropdownMenuItem for resend:
   - Add a `var remainingSeconds by remember { mutableIntStateOf(...) }` initialized from resendStatus.remainingMs / 1000

2. Add LaunchedEffect keyed on (showMenuForDevice, device.phoneNumber) that:
   - Only runs when the menu is showing for this device AND status is Cooldown
   - Every 1000ms, decrements remainingSeconds
   - Stops when remainingSeconds <= 0 or menu dismissed

3. Update the Text to show remainingSeconds instead of resendStatus.remainingMs / 1000:
   ```kotlin
   is ResendStatus.Cooldown -> Text("Resend (${remainingSeconds}s)")
   ```

4. When remainingSeconds reaches 0, the next recomposition from ViewModel will show CanResend status.

Note: The ViewModel's canResendPairingRequest() is called fresh each recomposition, but we need the UI to tick down without closing/reopening. The local remainingSeconds provides the ticking, and when it hits 0, the next ViewModel call will return CanResend.
  </action>
  <verify>./gradlew assembleDebug succeeds. Manual test: open dropdown during cooldown, observe countdown ticking from e.g. "Resend (45s)" down to "Resend (44s)" etc.</verify>
  <done>Dropdown countdown ticks down live every second while menu is open during cooldown period.</done>
</task>
