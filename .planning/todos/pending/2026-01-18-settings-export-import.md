# Settings Export/Import

**Created:** 2026-01-18
**Source:** Phase 12 discussion (deferred)
**Priority:** Low

## Description

Add ability to export and import app settings as JSON file for backup/restore purposes.

## Use Cases

- Backup settings before app reinstall
- Restore settings on new device
- Share settings configuration between devices

## Technical Notes

- Export all DataStore settings to JSON
- Import with validation and migration handling
- Consider security implications for any sensitive settings

Deferred from v0.0.63 — revisit in future version.
